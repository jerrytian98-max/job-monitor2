监测配置
“按关键词搜索”适合招聘首页或未筛选列表页，程序会逐个使用下方的职位关键词搜索。 “固定网址直抓”会保留 URL 已有的筛选条件，不提交职位关键词，只抓取该 URL 返回的职位。
多个关键词会分别搜索和抓取，例如网址标签“美团”与关键词“法务”会生成职位标签“美团法务”。
留空表示不限制
例如：实习、兼职
留空时不启用 AI 筛选；密钥只保存在本机配置文件中。
API Key 和筛选要求都填写时才会调用 Gemini。
请先保存当前邮箱配置，再发送测试邮件。
建议设置为2-4小时，避免频繁请求
GitHub 同步
Token 需要 Actions 读取和 Secrets 写入权限，只保存在本机 github_sync.yaml，不会上传到仓库。
下载前请先停止本地监测；覆盖前会自动备份现有数据库。
使用提示
  • 启动监测：点击"启动监测"按钮开始自动监测
  • 配置保存：修改配置后记得点击"保存配置"
  • 邮箱授权码：需要从邮箱设置中获取，不是邮箱密码
  • 测试检查：使用"测试检查"验证配置是否正确
  • 注意频率：监测间隔不要太短，避免被反爬虫
