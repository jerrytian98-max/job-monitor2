========================================
招聘监测系统 - 快速启动指南
========================================

【首次安装】

在本项目目录打开 PowerShell，执行：

python -m pip install -r requirements.txt
python -m playwright install chromium


【启动默认用户】

双击：启动Web服务-用户1(默认).bat
访问：http://127.0.0.1:5000


【启动第二用户】

双击：启动Web服务-用户2(分身).bat
访问：http://127.0.0.1:5001


【命令行测试】

python main.py --test --once

测试检查不会发送邮件，也不会写入职位数据库。


【停止】

网页中的“停止监测”会安全停止后台循环。
要关闭整个网页服务，请在启动窗口按 Ctrl+C 或关闭窗口。


【常见问题】

1. ModuleNotFoundError
   重新执行：python -m pip install -r requirements.txt

2. 找不到 Chromium
   执行：python -m playwright install chromium

3. 端口被占用
   默认用户使用 5000，第二用户使用 5001。关闭占用端口的程序后重试。

4. 没有收到邮件
   先在网页保存 SMTP 配置，再点击“测试邮件发送”。授权码不是邮箱登录密码。

5. 页面抓不到职位
   确认网址能在普通浏览器中打开，并适当降低访问频率。网站验证码和页面结构变化可能阻止自动提取。
